# Особый случай: Gigma Work Desktop

Применяй только если в текущем репозитории найдены `docs/graphify-local.md`, `scripts/graphify/Graphify.ps1` и `.graphify/processes.json`. Это локальная интеграция проекта; её пути и параметры не переносить на другие проекты.

Оставайся в найденном checkout; не перемещай и не копируй репозиторий ради Graphify. Все пути ниже относительны корня проекта. Перед использованием прочитай актуальные `.graphify/requirements.txt` и `scripts/graphify/Graphify.ps1`: launcher задаёт путь к изолированному окружению и может bootstrap-ить закреплённый пакет при несовпадении версии. Определи путь к Python и фактическую версию из launcher/окружения, не из имени папки или старой записи. Не зашивай машинные пути или номер версии в переносимую инструкцию.

## Штатные команды и свежесть

Из корня репозитория сначала прочитай `AGENTS.md` и `docs/graphify-local.md`. Учитывай, что `Graphify.ps1` может автоматически установить закреплённый пакет при несовпадении версии даже при вызове `query`. Сначала прочитай launcher и проверь установленную версию. В read-only задаче не запускай его repair/install при mismatch: либо сообщи точный mismatch, либо используй уже подтверждённый interpreter напрямую, установив `GRAPHIFY_QUERY_LOG_DISABLE=1` только в окружении этого процесса. Не меняй глобальные переменные.

Если launcher не запускает установку, штатные команды:

```powershell
.\scripts\graphify\Graphify.ps1 -Command serve
.\scripts\graphify\Graphify.ps1 -Command refresh
.\scripts\graphify\Graphify.ps1 -Command query -CliArgs @('вопрос по связям исходников')
.\scripts\graphify\Graphify.ps1 -Command path -CliArgs @('узел A', 'узел B')
.\scripts\graphify\Graphify.ps1 -Command explain -CliArgs @('имя узла')
```

Локальный просмотрщик использует `http://127.0.0.1:8768/`; это настройка этого проекта. Для свежести читай `/api/status`: успешный статус означает актуальную карту, когда `readySourceFingerprint` совпадает с `sourceFingerprint`. Ошибка оставляет прежнюю карту, но не делает её свежей. Не запускай второй watcher и не выполняй ручной refresh поверх работающей сборки.

Входной процессный каталог — `.graphify/processes.json`; его страницы выводятся по ID под `graphify-out/processes/`, общий граф и callflow — `graphify-out/graph.html` и `graphify-out/callflow.html`. Уточняй текущие процессы и шаги из каталога и метаданных сборки, не полагайся на сохранённые числовые ожидания.

## Codex MCP и проверки

Проектный `.codex/config.toml` работает только в доверенном проекте и после загрузки настроек в сессии. Проверь, что MCP tools реально появились в активном Codex сеансе; локальная конфигурация не доказывает hot reload. Запросы направляются в текущий `graphify-out/graph.json`. Сверяй реальный tool schema и ответ Graphify; в проверенной версии `get_node` не возвращал `description`, поэтому отсутствие этого поля не доказывает устаревший кеш.

Набор `.github/workflows/graphify.yml` локально готовит и проверяет artifact для pull request и push в `main`. Он не действует на GitHub, пока соответствующие коммиты не опубликованы и workflow реально не запущен; не называй локально успешную проверку удалённым CI.

Статический граф этого проекта не доказывает визуальное совпадение с донором Kimi Web/Desktop и не подтверждает внутреннюю реализацию отдельного donor CLI. Для этого нужны соответствующие исходники и отдельная проверка поведения. В установленном MCP Python SDK 2.3 поля Python-моделей snake_case; чтобы сверить wire-схему, смотри сериализацию с `model_dump(by_alias=True)`, а не имена Python-атрибутов.

В проверенном Graphify 0.9.102 ответы `query_graph` и `get_neighbors` содержали citation вида `source_file:line` для рёбер. `shortest_path` показывал маршрут, relation и confidence, но не source citation; отсутствие citation только в этом инструменте не означает, что MCP сломан. Для каждого вопроса используй доказательства, которые реально возвращает выбранный tool.

Проверенный снимок исходника: commit `c82d679b38ca492961fe74a8ffee6bd560fb0c7b`. На нём локальный набор Graphify содержал 19 тестов, 83 шага (77 AST-якорей и 6 source-only), 16 процессов и 68 переходов. Это только историческая контрольная точка: перед выводом бери актуальные fingerprint, каталоги, ответы MCP и результаты проверок из текущего checkout.
