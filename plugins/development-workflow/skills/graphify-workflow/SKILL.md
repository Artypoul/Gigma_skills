# Graphify в проекте

Используй Graphify для запросов к уже построенному графу, обновления графа и проверки его представлений. Граф показывает статические связи и кураторские схемы; он сам по себе не подтверждает поведение работающего приложения или внешнего API.

## Выбери доступный путь

- Если подключён Graphify MCP, следуй инструкциям этого подключения и используй только реально перечисленные инструменты и поля ответов. MCP может обслуживать другой граф; не запускай параллельно CLI-запрос к локальной копии без причины.
- Если нужен локальный CLI-граф, сначала проверь `graphify --help` и существование `graphify-out/graph.json`. Для вопроса по существующему свежему графу начни с `graphify query`; для связи двух узлов используй `graphify path`, для источника и соседей — `graphify explain`.
- Если проект описывает собственную Graphify-интеграцию, сначала прочитай её `AGENTS.md` и документацию. Используй её штатный launcher, watcher и критерии свежести вместо универсального предположения о настройках.
- Для новой установки сверяйся с установленной версией и документацией Graphify; не копируй команды из старого примера и не зашивай путь этой машины или номер версии в другой проект.

## Границы изменений

Структуру процессов, точность исходных якорей и проверку HTML/MCP смотри в [контрактах графа процессов](references/process-graph-contracts.md). Установка, обновление и выбор CLI/MCP описаны в [операциях Graphify](references/operations.md). Для этого рабочего стола есть отдельная [карта проекта](references/gigma-work-desktop.md); применяй её только если текущий репозиторий опознан по его файлам.

Не запускай полное извлечение ради одного простого поиска, если код можно быстро найти напрямую. Кодовый AST-граф обычно строится без LLM и API-ключа. Установка Graphify в среде, `graphify install`, изменение конфигурации MCP, hooks или постоянно работающих watcher относятся к разным действиям; выполняй только то, что разрешено задачей. `graphify install` может записать ассистентские инструкции, а hook меняет поведение Git — не включай их автоматически.

Перед выводом, основанным на графе, сверь его актуальность и подтверди важные связи исходным кодом. В аудите отделяй возможности нативного Graphify от расширений проекта и не представляй проектный вывод как доказанный факт без подтверждения источником.
