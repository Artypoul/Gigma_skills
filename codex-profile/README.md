# Codex profile

Этот каталог — переносимый профиль Codex для Windows.

Он собирает:

- канонические скиллы из `plugins/*/skills`;
- личные переносимые скиллы из `personal-skills/`;
- глобальные правила из `global-AGENTS.md`;
- необязательные feature-хуки из `hooks/`.

## Установка на новом компьютере

Откройте PowerShell в корне клонированного репозитория:

```powershell
pwsh -NoProfile -File .\codex-profile\setup.ps1
```

Чтобы установить feature-хуки:

```powershell
pwsh -NoProfile -File .\codex-profile\setup.ps1 -InstallHooks
```

Для проверки в отдельной папке можно передать `-CodexHome C:\Temp\codex-test`; по умолчанию используется `%USERPROFILE%\.codex`.

После обновления профиля достаточно выполнить `git pull` и снова запустить `setup.ps1`.

## Безопасность и конфликты

Скрипт устанавливает только скиллы, которыми сам управляет, и не удаляет чужие папки из `%USERPROFILE%\.codex\skills`. Если глобальный `AGENTS.md` или `hooks.json` уже существуют и отличаются, скрипт оставляет их без изменений. Для осознанной замены используйте `-AdoptGlobalAgents` или `-AdoptHooks`; перед заменой создаётся резервная копия.

В профиль намеренно не входят `auth.json`, токены, SQLite-базы, история сессий и абсолютные пути к локальным runtime. На новом компьютере нужно войти в тот же ChatGPT/OpenAI аккаунт отдельно.

Приватные локальные скиллы с конкретными серверами, IP-адресами или путями к ключам в публичный репозиторий не включаются; их нужно хранить отдельно.

## Что не переносится этим профилем

Настройки конкретных MCP-серверов с секретами, OAuth-подключения и машинные пути настраиваются на новом компьютере отдельно.
